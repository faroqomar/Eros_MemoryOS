# Design Context

## Users and purpose
Eros uses MemoryOS as an iPhone-first personal memory app. Capture thoughts and connect people, projects, conversations, and birthdays. The browser prototype uses fictional data and supports Arabic and English.

## Current owner direction
The owner rejected the restrained Astryx design and then rejected the wild editorial design. When asked for a positive reference, the owner selected Apple design. The current interpretation is Apple's iPhone app design language. This choice supersedes the wild palette, poster type, illustrated portraits, and decorative motion. The original home image is historical, not a current pixel constraint.

## Personality and visual system
Use familiar iPhone structure: system typography, large section titles, clear hierarchy, grouped surfaces, subtle separators, blue actions, and red recording controls. Keep content surfaces opaque. Reserve translucency for navigation. Use initials for fictional people, simple folder symbols for projects, and a quiet linked-record canvas. Support light and dark appearance in the preview.

## Design principles
- Prioritize the task and content over decoration.
- Use familiar navigation and clear button labels.
- Keep readable text, comfortable touch targets, and consistent spacing.
- Make Arabic layout natural and preserve original note language.
- Keep motion brief and functional; respect reduced motion.
- Treat this as Apple-inspired browser design, not native UIKit or SwiftUI delivery.
- Preserve rejected versions as history. The new design still needs owner review.
