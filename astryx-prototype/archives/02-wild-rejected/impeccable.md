# Design Context

## Users and purpose
Eros uses MemoryOS as a personal, iPhone-first second brain. Capture thoughts and connect people, projects, conversations, and birthdays. The browser prototype uses fictional data and supports Arabic and English.

## Current owner direction
On 2026-11-13 the owner rejected the restrained Astryx prototype and requested a complete wild redesign. The owner explicitly released prior visual rules. The retained home image and hidden-sidebar rule are historical references, not constraints on this redesign.

## Brand personality
Expressive, personal, playful, and adventurous. Use an editorial art direction with bold contrast, oversized typography, tactile color, and purposeful motion. Keep the actual tasks usable.

## Visual system
Use ink, warm paper, acid yellow, coral, cobalt, and sage. Pair self-hosted Geist with italic display serif accents. Give each section a distinct composition: a capture poster, illustrated people, project covers, a birthday calendar, and an orbital map. Use a visible mobile dock and desktop side navigation.

## Design principles
- Redesign composition and interaction, not only colors.
- Let one focal point lead each screen.
- Make illustrations original, local, and clearly fictional.
- Keep sources, tentative ideas, and user corrections legible.
- Use motion for feedback and transitions. Respect reduced motion.
- Test the phone layouts, both languages, and the main interactions.
- Retain rejected designs as history. This direction still needs owner review.
