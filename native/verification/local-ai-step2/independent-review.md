## Actual architecture trace

- **View:** `native/MemoryOSAILab/LabView.swift:47` forwards selection to `model.select`; line 79 forwards Run to `model.run`; line 76 forwards Cancel. The View owns language/export sheet presentation state. It imports the core contract, SwiftUI and document UTTypes, with no SDK or database imports.
- **ViewModel:** `EvaluationViewModel` in `native/LocalAIEvaluation/Sources/AIEvaluationPresentation/EvaluationViewModel.swift` owns selection, running/progress/result/error/export state. `run()` invokes the injected `EvaluationRunning`, rejects concurrent runs and guards late publication after cancellation. It keeps `running` true until the worker returns. Seven independent presentation tests exercise success, failure sanitization, invalid selection, progress, immediate cancellation and noncooperative late completion.
- **Use case:** `RunEvaluationComparison` creates one adapter session per batch, measures each suite, awaits atomic report writing before continuing, and cleans up on success/error/cancellation. `EvaluationRunner` owns the shared prompt rules, ground-truth isolation, result validation and source scoring. The independent core imports Foundation only and compiles without SDKs or SwiftUI.
- **App-owned contracts:** `SourceRecord`, `TextRequest`, `RetrievedSource`, `TextOutput`, `MemoryIndexAdapter` and `TextRuntimeAdapter` cross the boundary as values. Expected IDs and grading guidance stay in the evaluator. Text runtimes receive the same entire canonical corpus, separately from retrieval.
- **Adapters:** provider SDK imports occur in dedicated adapter targets. Llama handles remain inside one actor call; a retained session resets context/sampler per request and unloads on batch cleanup. Cactus owns one native model/index at a time, stages rebuilds, publishes only completed replacements and maps stable canonical IDs. Wax rejects actor reentrancy while awaiting SDK operations and stages replacements. MLX prevents overlapping generation, cancels and joins its stream worker, and verifies reviewed local assets on cold load. Simulator availability uses a separate SDK-free module and reports unsupported inference without output.
- **Composition:** `native/MemoryOSAILab/LabComposition.swift` supplies concrete SDK adapters, source/model pins, local sandbox paths, sampling and report writing. `MemoryOSAILabApp` selects dark mode. The main Capture app/store are separate targets and are outside these experiment data paths.
